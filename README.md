# Sistema de Agendamento de Consulta - Especificação de Requisito

## 1. Visão Geral
Este documento especifica os requisitos funcionais do módulo de agendamento

##2. Requesitos Funcionais (RF)
-[] RF01: O paciente deve conseguir visualizar os horários disponíveis de cada médico
-[] RF02: O sistema deve permite o agendamento de consultas com confirmação por e-mail.
-[] RF03: O médico deve visualizar sua agenda diária e semenal

##3. requísítos não Funcionais (RNF)
-RNF01 (Desempenho): O tempo de resposta para buscar de horários não deve exceder 2 segundos.
-RF02 (segurança) : Dados sensíveis de saúde devem estar em conformidade com a LGPD.
